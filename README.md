# Machine Learning Projects

Documenting my machine learning journey through practical projects, Python code, clear explanations, experiments, and model evaluation.

## About

I'm Shanmukha Vardhan Reddy Katigari, a student at Manipal Institute of Technology.

I'm building this repository to develop my understanding of machine learning by working through problems, explaining my decisions, and learning from the results. Projects will be added gradually as I build and document them.

## Learning Goals

- Explore datasets and understand the problem before choosing a model.
- Handle missing values, prepare features, and visualize patterns.
- Build simple baselines and compare different models.
- Evaluate performance on unseen data using suitable metrics.
- Recognize overfitting, data leakage, and model limitations.
- Explain what worked, what failed, and what I would improve.

## Project Documentation

Each project will have its own folder and README covering:

1. **Problem:** What I am trying to predict or understand.
2. **Dataset:** Source, relevant features, and usage requirements.
3. **Approach:** Data preparation, baseline, model choices, and evaluation setup.
4. **Results:** Measured performance, comparisons, and example outputs.
5. **Limitations:** Errors, assumptions, and possible improvements.
6. **How to run:** Required dependencies and execution steps.
7. **What I learned:** Key takeaways and references used.

Tutorials, datasets, and borrowed code will be credited, with my own experiments and changes explained.
